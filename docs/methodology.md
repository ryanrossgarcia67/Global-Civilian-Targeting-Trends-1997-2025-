# Methodology

## Project Objective

The objective of this project is to visualize long-term global trends in civilian targeting events using aggregated conflict event data from the Armed Conflict Location & Event Data Project (ACLED).

The dashboard was designed to support exploratory analysis of:
- Temporal escalation patterns
- Geographic concentration of violence
- Country-level conflict persistence
- Long-term changes in civilian targeting activity

---

# Data Source

Source:  
https://acleddata.com/aggregated/number-events-targeting-civilians-country-year

The dataset was obtained from ACLED aggregated data tables containing yearly civilian targeting event totals by country.

ACLED collects and publishes conflict event data related to:
- Political violence
- Armed conflict
- Civilian targeting
- Protest activity
- Militia and insurgent activity

---

# Data Preparation

The dataset was prepared prior to visualization using Microsoft Excel.

Preparation steps included:
- Verification of yearly event totals
- Standardization of country naming conventions
- Formatting fields for Tableau geographic mapping
- Removal of incomplete or non-applicable entries
- Structuring data for time-series visualization

The final dataset was organized by:
- Country
- Year
- Number of civilian targeting events

---

# Dashboard Design

The dashboard was designed using Tableau Public with emphasis on clarity, accessibility, and exploratory analysis.

The visualization structure includes:
- Global geographic mapping
- Year-by-year trend visualization
- Interactive country filtering
- Comparative temporal analysis

Design considerations included:
- High-contrast dark theme for readability
- Simplified visual hierarchy
- Interactive filtering for exploratory use
- Consistent geographic representation

---

# Analytical Notes

The visualization highlights several observable trends within the dataset.

Key observations include:
- Significant growth in recorded civilian targeting activity after the early 2010s
- Persistent concentration of events within conflict-prone regions
- Expansion in the geographic distribution of events during later years
- Long-duration conflict persistence within select states

The dashboard is intended to support exploratory analysis rather than predictive modeling or causal attribution.

---

# Limitations

Several limitations should be considered when interpreting the data.

- The dataset reflects recorded and reported events, which may vary based on reporting capacity and conflict accessibility.
- Aggregated yearly totals do not capture event severity or casualty scale.
- Geographic aggregation at the country level limits subnational analysis.
- Changes in reporting infrastructure over time may influence event visibility.
